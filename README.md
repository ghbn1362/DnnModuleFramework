# DnnModuleFramework

A lightweight, extensible and opinionated framework for building **DotNetNuke (DNN)** modules with a clean and maintainable architecture.

The framework provides a reusable foundation for DNN module development, reducing boilerplate code and encouraging best practices.

---

## Features

- ✔ Clean Architecture
- ✔ Base Module Classes
- ✔ Service Factory
- ✔ Dependency Injection Ready
- ✔ Centralized Context Management
- ✔ Skin & Asset Management
- ✔ Reusable Services
- ✔ Strong Separation of Concerns
- ✔ Easy Module Development
- ✔ .NET Framework 4.7.2
- ✔ DNN 10.x Compatible

---

## Project Structure

```
DnnModuleFramework
│
├── Core
├── Services
├── Security
├── Skin
├── Helpers
├── Extensions
├── Base Classes
└── Shared Resources
```

---

## Requirements

- .NET Framework 4.7.2
- DotNetNuke (DNN) 10.x
- Visual Studio 2015 or later

---

## Goals

This framework was created to simplify DNN module development by providing:

- A consistent architecture
- Reusable infrastructure
- Reduced code duplication
- Better maintainability
- Easier testing
- Faster development

---

Clone the repository
